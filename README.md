# Students Own the Reasoning

Supplemental materials for the Faculty GenAI Showcase by Cy McGinnis, UMGC Asia.

Students choose a story, GenAI builds an invented dataset, and students analyze it in Statdisk without GenAI.

## Contents

- `index.html`: the showcase in five parts, the student assignment, and two copyable fill-in prompts. One file, no external dependencies. Works offline.
- `Statistics_Story_Project_Assignment.docx`: the student assignment.
- `Fill-In_Prompt_for_Any_Discipline.docx`: the fill-in prompt for any discipline, with a worksheet.
